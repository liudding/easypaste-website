## 修复"首页博客入口看不见"问题（用户反馈入口没了）
- 经解析校验：index.html 中 `id="blog"` 板块与 3 处 `/blog/` 链接均存在且标签平衡（无未闭合），所以不是"链接丢失"，而是**可见性问题/陈旧预览**。
- 根因防范：首页 `.fade-up` 动画默认 `opacity:0`，若滚动观察器未触发会永久隐藏区块。已做渐进增强：
  1. `<head>` 加 `document.documentElement.className += ' js'`，仅当 JS 可用时才隐藏 `.fade-up`（`.js .fade-up { opacity:0 }`）。
  2. 观察器包 `try/catch`，不支持时直接全部显示。
  3. 新增 `window.load` 后 1.5s 兜底：仍未 `.visible` 的 `.fade-up` 强制显示。
- 已启动本地预览 `http://127.0.0.1:3000/`（python http.server，后台 task kLglnf），用于确认当前文件真实渲染。
- 提示用户：若看的是已部署 URL（vercel.app），需重新部署才会生效；本地预览即最新代码。
